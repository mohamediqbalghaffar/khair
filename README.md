# سیستەمی بەڕێوەبردنی داتابەیسی کاری خێرخوازی (ڕێکخراوی بۆتان بامۆکی)
### Modern Charity Work Database & Aid Distribution Web Application

سیستەمێکی سەردەمییانەی تەواو بۆ بەڕێوەبردنی داتابەیسی ڕێکخراوە خێرخوازییەکان، بە دیزاینی پێشکەوتووی **iOS 26 Liquid Glass**، بە زمانی شیرینی **کوردیی ناوەندی (CKB)** و فۆنتی فەرمی **Speda-Bold**.

---

## تایبەتمەندییە سەرەکییەکان (Features)

1. **بەڕێوەبردنی سوودمەندان (Beneficiaries Management)**
   - تۆماری تەواوی خێزانە کەمدەرامەتەکان و بێباوکان بە ژمارەی نیشتمانی، ژمارەی ئەندامانی خێزان و داهات.
   - سیستەمی زیرەکی **دۆزینەوەی ساختەکاری و دووبارەبوونەوە (Duplicate Detection)** بۆ ڕێگری لە هاوکاری چەندبارە.
   - مێژووی تەواوی هاوکارییە نەختینەیی و کاڵاییە پێدراوەکان بۆ هەر خێزانێک.

2. **بەڕێوەبردنی بەخشەران و پسوولەی فەرمی (Donors & Official Receipts)**
   - تۆماری بەخشەرانی کەسی، دەزگاکان و کۆمپانیاکان بە دراوی دینار (IQD) و دۆلار (USD).
   - **دروستکەری پسوولەی فەرمی (Official Receipt Generator)** بە مۆری فەرمی، کۆدی QR و توانای چاپکردن.
   - سیستەمی ناردنی کورتەنامەی سوپاسگوزاری خۆکار (SMS Simulation).

3. **کۆگا و دابەشکردنی کۆمەک (Inventory & Direct Aid Distribution)**
   - بەدواداچوونی سەبەتەی خۆراک، جلوبەرگ، زۆپا، و پێداویستییە پزیشکییەکان.
   - ئاگاداری کەمبوونەوەی کۆگا (**Low Stock Alerts**).
   - دابەشکردنی ڕاستەوخۆ بۆ خێزانەکان لەگەڵ کەمکردنەوەی خۆکارانەی کۆگا.

4. **پڕۆژەکان و کەمپەینەکان (Projects & Campaigns)**
   - بەدواداچوونی کەمپەینە وەرزییەکان (گەرمایی زستان، سەبەتەی ڕەمەزان، تەندروستی، خوێندکاران).
   - بەراوردی گرافیکی ڕێژەی بودجەی دیاریکراو، کۆکراوە و خەرجکراو.

5. **دارایی و شەفافییەت (Financial Management & Ledger)**
   - دەفتەری داهات و خەرجییەکان بە دینار و دۆلاری ئەمریکی.
   - هەناردەکردنی ڕاپۆرتی دارایی بە فۆرماتی Excel / CSV.

6. **تیمی خۆبەخشان و کارتی ناسنامەی دیجیتاڵی (Volunteers & Digital Badges)**
   - تۆماری لێهاتووییەکان، گرووپی خوێن و کاتژمێرەکانی خزمەت لە مەیداندا.
   - دروستکردنی کارتی فەرمی خۆبەخش بە شێوازی چاپکراوی شایستە.

7. **نەخشەی جوگرافی کارلێککار (Interactive Kurdistan Aid Map)**
   - نەخشەی پارێزگاکانی هەولێر، سلێمانی، دهۆک، هەڵەبجە، کەرکووک، گەرمیان و زاخۆ.
   - چاودێری چڕی هاوکاری و دادپەروەری دابەشکردن بەپێی ناوچەکان.

8. **بەڵگەنامەکان و مێژووی چاودێری (Document Vault & Audit Trail)**
   - پاراستنی ناسنامەکان، ڕاپۆرتی پزیشکی و پسوولەکان.
   - تۆماری گشتگیری گۆڕانکارییەکان (Audit Trail) بەپێی ستانداردە نێودەوڵەتییەکان.

9. **دەسەڵاتەکان و گەڕانی خێرا (RBAC & Spotlight Search)**
   - گۆڕینی دەسەڵات: بەڕێوەبەر (Admin)، بەرپرسی پڕۆژە، کارمەند، خۆبەخش، بەخشەر، چاودێری دارایی.
   - پەنجەرەی گەڕانی چرکەیی بە دوگمەکانی `Ctrl + K`.

## تەکنەلۆژیاکان (Tech Stack)

- **Frontend Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom iOS 26 Liquid Glass System
- **Icons**: Lucide React
- **Effects**: Canvas Confetti
- **Typography**: Speda Bold Font (کوردی)
- **Deployment**: Vercel

---

## دابەزاندن و بەگەڕخستنی لۆکاڵی (Local Development)

```bash
# کلۆنکردنی پڕۆژەکە
git clone https://github.com/mohamediqbalghaffar/khair.git

# چوونە ناو فۆڵدەر
cd khair

# دابەزاندنی پاکێجەکان
npm install

# بەگەڕخستنی سێرڤەری گەشەپێدان
npm run dev
```
وە وێبگەڕەکەت بکەرەوە لەسەر: `http://localhost:5173`
