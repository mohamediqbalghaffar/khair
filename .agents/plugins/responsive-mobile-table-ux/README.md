# Responsive Tables, Mobile Dock & GeoMap UX Plugin

Ensures smooth responsiveness across desktop, tablet, and mobile viewports for data-heavy tables, the floating iOS 26 Navigation Dock, and interactive Leaflet maps.

## Included Customizations
- **Rule (`rules/AGENTS.md`)**: Enforces `PaginationBar` on large tables, horizontal scroll containers, touch target minimums, and GeoMap focus preservation.
- **Skill (`responsive-ux-audit`)**: Runbook for auditing table density, mobile breakpoints, and map sidebar interactions.
