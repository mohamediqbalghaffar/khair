# Smart Forms, Steppers & Bulk Import UX Plugin

Ensures frictionless data entry across Beneficiary registration, Donor receipt generation, Inventory distribution, and Document bulk uploads.

## Included Customizations
- **Rule (`rules/AGENTS.md`)**: Enforces controlled inputs, instant Kurdish/Arabic normalized combobox search, HTML5 drag-and-drop handlers, and `useFeedback()` toast notifications.
- **Skill (`form-ux-upgrade`)**: Checklist for auditing and upgrading complex forms, preset tag selectors, and Excel/file import wizards.
