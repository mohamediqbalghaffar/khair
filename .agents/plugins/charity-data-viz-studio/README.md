# Humanitarian Data Visualization & Impact Charts Plugin

Equips Antigravity with reusable patterns and rules for crafting responsive, zero-dependency SVG charts, gauges, funding thermometers, and RTL KPI cards tailored for humanitarian reporting.

## Included Customizations
- **Rule (`rules/AGENTS.md`)**: Standards for accessible SVG charts, zero-division guards, RTL bar progressions, and dual IQD/USD currency display.
- **Skill (`build-impact-chart`)**: Templates and recipes for Donut Gauges, Governorate Comparative Bars, and Project Budget Thermometers.
