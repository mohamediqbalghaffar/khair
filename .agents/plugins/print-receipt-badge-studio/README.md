# Official Print Studio, Receipts & ID Badges Plugin

Guarantees print-ready A4 and ID-card output for all official documents generated by the Botan Bamoki Charity Management System.

## Included Customizations
- **Rule (`rules/AGENTS.md`)**: Enforces `@media print` container isolation in `src/index.css`, `.no-print` action chrome hiding, exact background color printing, and official Kurdish header/signature blocks.
- **Skill (`design-printable-document`)**: Runbook for building and verifying printable donor receipts, volunteer badges, beneficiary dossiers, and impact reports.
