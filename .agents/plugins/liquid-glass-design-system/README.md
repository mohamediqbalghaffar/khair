# iOS 26 Liquid Glass Design System Plugin

Provides design tokens, surface hierarchy guidelines, micro-interaction keyframes, and component polish runbooks for the Botan Bamoki Charity Management System.

## Included Customizations
- **Rule (`rules/AGENTS.md`)**: Enforces translucent white glass surfaces, typography minimums, semantic badge palettes, and CSS entrance animations.
- **Skill (`liquid-glass-polish`)**: Step-by-step UI visual upgrade checklist for views, cards, and modals.
